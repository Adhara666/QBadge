## QBadge 0.4.0

- 内置 9,201 条期刊缩写索引：ISSN 缺失时可按 `Atmos. Meas. Tech.` 这类缩写匹配
- 设置页新增“期刊别名”：可手动添加 / 删除“缩写 → 完整刊名”映射
- 匹配顺序：ISSN → 手动别名 → 完整刊名 → 内置缩写
- 命中缩写或别名时，标签悬浮提示会注明匹配方式
